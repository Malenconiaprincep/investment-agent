# 同花顺模拟盘观察仓

本目录记录从 2026-07-13 开始的同花顺模拟盘策略袖套，和同花顺账户中的历史持仓分开核算。

## 落盘约定

- 同花顺模拟计划、执行结果和台账统一落在本目录，不再写入项目外的临时输出目录。
- 每日计划命名为 `YYYY-MM-DD-plan.md`；实际成交与跳过记录追加到 `ledger.jsonl`。
- 2026-07-10 的首次原始计划已归档为 `2026-07-10-plan.md`，其状态为“已制定计划、未提交模拟委托”。

## 风控规则

- 初始观察资金：50,000 元
- 仅允许同花顺“模拟”账户，禁止切换到 A 股真实账户下单
- 单股首次建仓不超过观察资金的 20%，同时最多 2 只，现金至少保留 60%
- 收盘后生成次日计划；开盘后只在触发条件满足时模拟成交
- 没有合格候选时必须记录空仓，不为“每天都交易”而交易
- 每笔计划记录行情日期、K 线条件、公告/财务证据、触发价、失效价和退出规则

同花顺账户的历史盈亏不计入本观察仓；本观察仓收益从首笔实际模拟成交开始单独计算。
