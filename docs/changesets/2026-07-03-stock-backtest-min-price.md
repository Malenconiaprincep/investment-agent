# 2026-07-03 股票回测策略低价过滤与次日执行优化

## 元信息

- Type: strategy
- Status: done
- Owner: codex
- Related: stock-backtest, red-diamond-momentum, paper-trading
- Created: 2026-07-03

## 背景

用户反馈 2026-04-04 至 2026-07-03 股票红钻动量回测明显跑输。复盘显示同期沪深300ETF基准约 +9.76%，默认策略约 +0.15%，主要拖累来自低价/高噪声候选和信号延迟确认后仍追高的个股，且简单关闭大盘过滤会恶化到约 -17.81%。

## 改动

- 股票红钻动量策略默认最低入场价从不限制提高到 8 元。
- 股票回测模拟盘扫描沿用相同最低入场价，避免回测与实盘候选口径不一致。
- 股票鲁棒性脚本中的默认/高质量变体标签同步为 8 元以上。
- 纯回测策略仓从收盘后按当日收盘价买入，改为交易日前 08:00 按前一交易日数据扫描并用盘口价买入。
- 回测策略仓卖出交收从人为 T+2 回到普通股票 T+1；T+2 仅保留为“红钻信号到入场确认”的策略延迟口径。
- 回测策略仓入场从严格红钻硬门槛改为动量启动信号：趋势多头、量能至少 1.2 倍、突破 20 日高点、MACD 金叉或柱转正。

## 影响范围

- 页面/功能：股票回测、股票回测模拟盘自动买入候选、模拟盘分仓说明。
- 策略/参数：`red-diamond-momentum` 默认 `minEntryPrice=8`；自动买入改为盘前执行；入场源改为动量启动。
- 数据/存储：无迁移。
- 定时任务：`stock-backtest-auto-run` 与 `stock-backtest-news-auto-run` 的候选池会减少低价票；本机定时任务新增纯回测策略仓 08:00 买入。
- Eval/Harness：股票回测鲁棒性脚本默认口径变化。

## 预期影响

- 收益：目标窗口 2026-04-04 至 2026-07-03 从约 +0.15% 改善到约 +4.29%；2026-01-01 至 2026-04-03 从约 +8.57% 到约 +13.79%；2025-07-01 至 2026-07-03 从约 +40.02% 到约 +52.11%。
- 入场源：进一步切换为动量启动后，正式回测目标窗口约 +20.86%，2025 下半年约 +36.94%，2025-07-01 至 2026-07-03 约 +105.07%。
- 风险：过滤低价噪声票，但目标窗口最大回撤从约 -8.29% 变为约 -10.58%，需继续观察。
- 稳定性：不采用无条件信号延迟漂移 2% 过滤，因为该口径在 2025 下半年趋势行情显著伤害收益。
- 用户体验：默认回测结果更接近可交易股票池，减少明显低价候选；模拟盘不再展示“收盘后买入/T+2交收”的混合口径。
- 系统评分：策略验证分应提升，风险分需要结合模拟盘回撤继续观察。

## 验证

- 已运行：`runDiamondBacktest` 多窗口参数对照。
- 结果：8 元最低价在目标、相邻、全年窗口均改善收益；过强漂移过滤在长趋势窗口不稳。
- 未覆盖风险：尚未跑完整固定历史压力场景；回测仍按日线收盘统计，盘前真实盘口成交可能与回测价格有滑点。

## 观察指标

- 每日：股票回测模拟盘候选数量、成交数量、单笔大亏数量。
- 每周：策略收益、最大回撤、低价过滤数量、空仓暴露。
- 每月：与沪深300ETF基准的超额收益，以及是否持续跑输强趋势行情。

## 回滚方案

如果模拟盘连续恶化或全量鲁棒性回测显著下降，将 `DEFAULT_MIN_ENTRY_PRICE` 恢复为 0，并将 `STOCK_STRATEGY_PAPER_CONFIG.minEntryPrice` 恢复为原口径。
